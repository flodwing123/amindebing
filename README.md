# 🌿 啊敏的兵 · 班主任工作台使用说明书

> 初中道德与法治老师 & 班主任专用 · 电脑端 / 手机端工作台
> 数据默认保存在浏览器本地（localStorage），可一键备份/恢复实现**手机电脑互传同步**。
> 🛡️ 内置 **16 大模块**（含 📊 成绩分析 / ⚠️ 违纪统计 / 📮 请假管理 / ☁️ 云端同步），**所有输入内容自动留档、永不丢失**。
> 📱 手机版：网页支持 **PWA 安装到桌面**（像 App 一样全屏离线运行），另有 **APK 打包工程**（见 `mobile/APK打包指南.md`）。

---

## 🚀 快速开始

1. 电脑端：打开云端分享链接（或本地 `index.html`）；手机端：浏览器打开同一链接 →「添加到主屏幕」即可当 App 用
2. 左侧是**功能栏**，点击任意模块进入；**鼠标悬停模块名会弹出灵动小标签**，点击模块后**子菜单展开**可快速定位到具体栏目
3. 右侧是**内容详情**，每个栏目都配有工具条：✏️ 修改 / 💾 保存 / ⬇️ 导出 / 🖨️ 打印
4. 顶部有**今日任务进度条**，完成打勾即可

## 📱 手机 App（APK）与数据同步

- **打 APK**：打开 `mobile/APK打包指南.md`，三种方案任选（Capacitor+Android Studio 打包 / HBuilderX 云打包 / PWA 直接添加到主屏幕）
- **手机 ↔ 电脑同步**：两种方式——
  - **☁️ 云端自动同步**：在「数据保险库」配置免费云端 JSON 存储（如 jsonbin.io），数据变更后自动推送，打开时自动拉取，真正实现手机电脑实时同步
  - **💾 手动备份互传**：任一端点「💾 备份」下载 JSON → 微信/QQ 传到另一端 → 点「📥 恢复」选择文件
- 建议：每天下班前备份一次，每周双端同步一次

## 📆 模块12 · 每月小结（AI 月度汇报 PPT）

- **🤖 AI 四板块汇总**（点「🤖 AI 汇总本月」自动生成，可编辑后保存）：
  - **出勤表现**：当月出勤率 / 迟到缺勤情况 / 全勤之星（只表扬姓名）

## 🔐 V9 · 邮箱登录 + 多设备云同步（Supabase）

- 登录方式：邮箱 + 密码注册/登录（无验证码，注册即登录）；token 持久化，刷新不掉线
- 多设备：登录后数据自动同步到 Supabase 云端数据库，手机/电脑/平板登录同一账号即互通
- 数据安全：所有表开启行级安全（RLS），每个用户只能读写自己的数据；退出登录自动清除本地缓存，账号之间完全隔离
- 实现：原生 `fetch` 自写最小客户端（`js/supabase.js`），无官方 SDK、无框架；连接配置在 `js/sb-config.js`
- 数据库表结构与 RLS 脚本：`supabase/schema.sql`；部署与验证指南：`supabase/部署与验证指南.md`
